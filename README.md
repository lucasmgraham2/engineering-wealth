# Financial Guide for Engineers

A simple landing page for sharing a free financial guide designed for engineers and technical professionals.

## Overview

The website allows visitors to:

- Learn about the financial guide
- Enter their email to receive the guide
- Subscribe to future newsletter updates
- Unsubscribe from the newsletter

The website is hosted using GitHub Pages and connects to Google Apps Script for email signup and subscriber management.

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages
- Google Apps Script
- Google Sheets
- Google Drive
- Gmail
